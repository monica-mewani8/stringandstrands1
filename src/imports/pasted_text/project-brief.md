PROJECT BRIEF

Design and build a mobile-responsive homepage for an online jewellery brand called "Strings & Strands."

This is an e-commerce jewellery homepage. Reference layout structure: eternz.com (an Indian jewellery marketplace). Reference color palette/mood: estailofashion.com (a K-fashion-inspired accessories brand with a bold pink/magenta identity). Combine them: Eternz's layout skeleton + Estailo's color energy, executed as an original design (do not copy any real logos, product photography, or text copy verbatim).


1. BRAND IDENTITY & LOGO

Generate a logo for "Strings & Strands":


Concept: the name literally suggests linked strands of jewellery — build the mark around an interlocking thread/chain motif. Good directions to try: two looping, interwoven strands forming an infinity/knot shape; or the ampersand-style "S&S" monogram with the strands of the "S" letters visually linking into one continuous line.
Style: elegant, minimal, boutique-jewellery feel — thin-to-medium line weight, not cluttered, should work as a tiny favicon and also as a large hero mark.
Format: wordmark + icon lock-up ("Strings & Strands" in a refined serif or high-contrast serif/didone typeface, e.g. similar in spirit to Playfair Display, Cormorant, or Canela, paired with the interlinked-strand icon to the left).
Color version: primary logo in the brand's deep charcoal/near-black (#1A1A1A) for use on light backgrounds, plus a reversed white version for dark/hero sections, plus a magenta-accent version for promotional use.
Provide the logo as a component so it can be reused in the header and footer.

5. MOBILE RESPONSIVENESS REQUIREMENTS

Build true responsive breakpoints, not just a scaled-down desktop:


Desktop (≥1200px): full multi-column layouts, 7-across category circles, hover states active (Add to Bag on hover, dropdown nav on hover).
Tablet (768–1199px): category circles reflow to scroll or 5–6 per view; product carousels show 3–4 cards at a time.
Mobile (≤767px):

Header collapses to hamburger + logo + search icon + cart icon.
Category grid becomes a single horizontally swipeable row (this must exactly preserve the "circle + label" visual style from the screenshot, just in a scrollable strip instead of a fixed grid).
All product/collection carousels become swipeable with visible partial-next-card peeking (signals scrollability).
Sticky "Add to Bag" behavior becomes tap-to-reveal rather than hover.
Footer columns collapse into accordions.
Font sizes scale down proportionally; maintain minimum 14px body text and 44px minimum tap targets for buttons/icons.
Bottom of screen: consider a sticky mobile-only bottom nav bar (Home / Categories / Wishlist / Cart / Account) — optional but recommended for jewellery e-commerce UX.






6. INTERACTION / POLISH NOTES


Use soft rounded corners (8–16px radius) throughout for a modern, approachable feel — not sharp edges.
Subtle drop shadows on cards and circular category images (avoid heavy/harsh shadows).
Micro-interactions: heart icon fills magenta with a small bounce on wishlist tap; buttons have a slight scale/darken on press; carousel dots animate on slide change.
Use placeholder jewellery/lifestyle photography (no real brand photos) — soft, warm-toned, editorial style consistent with a premium accessories brand.
Maintain consistent 24px/16px/8px spacing rhythm across all sections for visual rhythm.
